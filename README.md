# Asteroids Game
## Tutorial Exercise 1: Basic Character Management and Drawing

### Introduction

This term in CPSC 453 (Fall 2026), you will explore foundational conceptual and systems-level ideas in Computer Graphics by implementing a simple 2D game. The project is inspired by the classic arcade game [Asteroids](https://en.wikipedia.org/wiki/Asteroids_(video_game)), which features a ship navigating 2D space while targeting asteroids. The ship uses basic control mechanisms to adjust its position and orientation. A demo of the original game is available on [YouTube](http://youtube.com/watch?v=BgloG8yt-jA).

### Ship Representation

In our version of the game, we will represent the ship as a [triangle strip](https://www.sfml-dev.org/tutorials/3.1/graphics/vertex-array/#primitive-types) composed of two triangles. Define the vertices in the exact order listed below:

`(-0.7071, -0.7071), (1.0, 0.0), (0.0, 0.0), (-0.7071, 0.7071)`

### Tasks

Starter code for the game is provided in this repository. The primary learning objective of this exercise is to familiarize yourself with setting up the rendering and UI loops, as well as organizing geometry data for rendering. 

Your TA will guide you through the starter code structure. Complete the missing sections marked in the codebase, then compile and run your program to verify that the ship renders on screen. Do not be concerned if the ship appears oversized or incorrectly oriented; these aspects will be addressed in the next tutorial exercise.
